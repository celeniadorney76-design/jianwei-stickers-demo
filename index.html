在 Android Chrome 上使用

  1. 点下方按钮，复制书签代码。
  2. 在 Chrome 中将本页添加到书签，然后打开书签管理并编辑书签：名称改为「见微表情」，网址替换成刚复制的整段代码，保存。
  3. 在 chatgpt.com 网页登录你的 Plus 账号。
  4. 点地址栏，输入「见微表情」，点击带书签图标的联想项（不要直接按搜索键）。
  5. 如果右下角出现“见微表情测试已启动”，让助手输出 [JW_HAPPY] 做实验。

这是书签脚本，并不是安装浏览器扩展。刷新 ChatGPT 页面后可能需要重新运行。

本实验的边界

只修改当前浏览器看到的助手回复，不修改 ChatGPT 服务器保存的文字。脚本只查找助手消息中的 [JW_HAPPY]；不会把对话发到我们的服务器。浏览器加载图片时会向 GitHub Pages 请求公开演示图。

这是 Chrome Android 书签脚本可行性实验；不同手机浏览器和 ChatGPT 页面版本可能不兼容。不能直接在 ChatGPT 官方 Android App 中执行。
